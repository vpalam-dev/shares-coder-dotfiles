# Coder Dotfiles

Install script for AI coding CLI tools used in Coder workspaces.

```bash
./install.sh
```

## Installed Tools

- Claude Code (`claude`)
- Codex (`codex`)
- Cursor CLI (`cursor-agent`, `agent`)
- Unpeel (`unpeel`)

Everything is installed into `~/.local/bin`, which the script adds to `PATH`
in `~/.bashrc`, `~/.zshrc`, and `~/.profile`.
